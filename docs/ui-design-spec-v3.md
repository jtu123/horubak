# 호루박 UI 설계명세 v3 — 데스크톱 구현 기준

공식 프로젝트명: AI 결합 영상물 하이라이트 숏폼 자동 제작 시스템.
기준: 사용자 지시와 product-redesign-v3-proposal.md. 기존 v2는 이전 기록으로 보존한다.

## 구현 범위와 구분
모든 분야의 영상물을 대상으로 등록과 탐색 구조를 확장한다. 분야 제한 제거가 모든 입력 형식·길이·AI 품질의 무제한 보장을 뜻하지는 않는다.
이번 구현은 **브라우저 데모 UI와 실제 로컬 편집 상태**다. 실제 인증·AI 분석·업로드·작업 큐·DB·MP4 합성·외부 게시·협업·과금은 연결 전이다.

데스크톱 창 너비 **1280px 이상**만 지원한다. 모바일 레이아웃·터치 흐름·휴대폰 목업·390px 검수는 구현/검수 범위에 넣지 않는다. 작은 창은 데스크톱 배치와 가로 스크롤을 유지한다.

## 정보구조
| 계층 | 경로 | 주요 행동 |
|---|---|---|
| 프로젝트 | /projects | 검색·특성 필터·정렬·카드/목록·즐겨찾기·이름 변경·삭제 확인·시각 샘플 추가 |
| 새 영상 | /projects/new | 파일/URL/샘플, 선택적 제작 목적·관심 대상·특성, 프로젝트 만들기 |
| 프로젝트 허브 | /projects/:id | 추천 후보 / 내 클립 / 원본 탐색 / 작업·출력 |
| 클립 편집 | /projects/:id/editor?clip=id | 선택 클립의 구간·자막·구도·근거·맥락 비교·undo·원본 재연결 |
| 편집 결과 | /projects/:id/results?clip=id | 선택 클립의 JSON·가능한 샘플 SRT, MP4 미연결 표시 |
| 라이브러리 | /library | 프로젝트 원본 목록·로컬 브랜드 프리셋 저장/미리보기 |
| 작업센터 | /jobs | 브라우저 데모 작업 목록·기존 시뮬레이션 취소/재시작 |
| 추가 작업공간 | /publishing, /team, /analytics | 설명 가능한 미연결 상태. 계정 연결·게시·협업·성과를 꾸며내지 않음 |
| 설정 | /settings | 테마·편집 JSON 백업, 외부 연결/사용량/결제의 미연결 상태 |

기본 메뉴는 프로젝트·라이브러리·작업센터. 게시·팀·성과는 더보기 아래에 둔다.
기존 로그인/가입·가운데 배치·계정 메뉴·빠른 실행·키보드 포커스를 유지한다. 소개용 큰 영역을 로그인에 다시 추가하지 않는다.

## 화면과 조작 계약
### 프로젝트·등록
- 장르 3종 필수 입력을 제거한다. 일반 영상과 혼합 특성을 수용하며 기존 장르는 레거시 프리셋/태그로 보존한다.
- 제작 목적·관심 대상·영상 특성은 사용자가 직접 지정하는 설정이다. 자동 인식 완료처럼 표시하지 않는다.
- 기존 사용자의 목록 개수·제목·즐겨찾기·편집은 보존한다. 새 시각 샘플은 버튼으로 명시적으로 추가할 수 있다.
- 새 파일 등록은 서버 전송 없이 브라우저 미리보기를 사용한다. URL은 주소만 기록한다.
- 새 등록 뒤 모의 대기 시간을 만들지 않고 프로젝트 허브로 이동한다. 직접 영상의 분석 결과가 없으면 연결 전을 표시한다.

### 후보·클립·원본
- 후보와 독립 저장 클립을 구분한다. 채택은 새 클립 생성 또는 이미 채택한 클립 열기이며 기존 편집을 덮지 않는다.
- 명시적 복제·이름 변경·삭제 확인을 지원한다. 삭제 시 다른 클립의 값은 유지한다.
- 전사·장면/음향 근거를 구분하고 해당 원본 시간으로 이동한다.
- 무음 시각 샘플에는 발화와 SRT를 만들어 넣지 않는다. 직접 등록 영상에는 샘플 후보를 실제 분석으로 표시하지 않는다.

### 편집·결과
- 클립별 편집과 되돌리기 이력을 분리한다. 다른 클립으로 이동해도 자막·구도·구간을 보존한다.
- 원본 타임라인은 구간 표시·탐색·시작/끝 수치 입력을 사용한다. 기존 장식 파형·비활성 트림 핸들은 제거한다.
- 실제 오디오 파형·드래그 트림·자막 cue 편집·실제 자동 추적은 이번 구현 완료로 보고하지 않는다.
- 맥락 근거·보정 전후 비교·적용·undo는 기존 샘플에서 동작한다.
- 실제 원본 재연결은 파일·메타데이터 검증 후 반영하고 기존 편집값을 보존한다.
- 결과 JSON은 출력 형식 schemaVersion2, 선택 clipId/편집 상태, rendered:false를 포함한다. 브라우저 저장 형식 v3와 출력 JSON의 버전은 별도이며 영상 출력 성공으로 표시하지 않는다.
- 샘플 SRT는 발화가 있는 샘플의 유효 구간에만 제공한다. 자막 문구 하나의 미리보기와 시간별 SRT는 아직 별개다.
- 기존 30~60초 편집 길이 검증을 유지한다. 새 출력 길이 프로필은 후속 기능이다.

## 시각·상호작용
중립 표면·파란 포인트·라이트/다크를 유지한다. 실제 작업화면의 글자는 의미 있는 정보로 채우며 목업용 회색 막대를 기능 화면에 적용하지 않는다.
사이드바216px·상단56px, 기존 시스템 글꼴과 공통 디자인 토큰을 사용한다.
편집은 244px / 중앙 최소400px / 264px, 간격16px로 구성해 1280px에서 필수 조작을 보존한다.
검색·탭·키보드·재생은 즉시 반응하며 포인터120ms·간헐 메뉴/대화상자160ms의 기존 Emil 기준을 따른다.
상태는 색 외 문구·아이콘으로 표현한다. 미연결·오류를 성공 토스트로 대체하지 않는다.

## Stageshow 적용 계약
- 사용 위치: 새 영상 등록 화면의 보조 영역.
- 매체: **정적 제품 시연**. 커서 루프·자동 데이터 변경·실제 버튼 위 가짜 클릭은 넣지 않는다.
- 목표: 추천 장면 하나가 독립 클립으로 보관되는 관계를 한 장에서 설명한다.
- 원본: Stageshow 1.1.1의 examples/static-card. 창·목록·전경 결과 카드와 크롭 구조를 재사용하고 콘텐츠·색·아이콘·한글을 호루박에 맞췄다.
- 20개 데스크톱 전이 의존 모듈과 최소 barrel을 포함한다. Phone 구현은 가져오지 않았다.
- 실제 Stage·Window·Row·Text·Bar 키트를 사용한다. 기존 Lucide 아이콘을 사용하며 새 외부 글꼴/이미지/패키지를 추가하지 않았다.
- 제작 흐름 예시이며 실제 분석 결과가 아니라는 짧은 설명을 붙인다.
- MIT LICENSE·NOTICE를 컴포넌트 디렉터리에 보존한다.
- 검수용 stageshow-reference.html은 개발 서버 전용 보조 진입점이며 일반 앱 내비게이션과 프로덕션 엔트리에서 사용하지 않는다.

## 데이터 보존·이전
Project.edit는 선택 클립의 호환 값으로 유지한다. 기존 편집은 결정적인 legacy clip ID로 이전한다.
같은 v1 저장 키를 유지하되 .backup.v3 백업을 먼저 만든다. 미지원 장르 한 개 때문에 전체 목록을 샘플로 대체하지 않는다.
손상 자료·백업 실패 시 원본 보존과 자동 저장 제한·복구 안내를 제공한다. 재실행으로 클립을 중복 생성하지 않는다.
로컬 데모 계정·completed 상태를 서버 인증·MP4 성공으로 승격하지 않는다.

## 검수 기준
모델 38개 단위 시험·TypeScript·프로덕션 빌드와 실제 브라우저 검수를 구분한다.
프로젝트/등록/허브/클립/결과/보조 화면을 1280×800·1440×900·1920×1080 및 라이트/다크에서 검사한다.
검색·메뉴·클립 독립성·맥락 보정·undo·다운로드 내용·새로고침·원본 재연결·업로드 제거 버튼을 확인한다.
Stageshow는 정적 --still --gate 결과와 독립 시각 검토를 REHEARSAL.md에 기록한다. 정적 검수를 애니메이션 통과로 보고하지 않는다.
실행 증거·남은 미검증 범위는 ui-review-v3.md를 따른다.
