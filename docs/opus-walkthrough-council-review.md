# OpusClip 영상 분석과 호루박 도입 결정

기준일: 2026-11-06. 대상: [공식 OpusClip 튜토리얼](https://www.youtube.com/watch?v=dvO5NsYovM4), 31분31초.
호루박 기준: UI v3 및 제품·계획서·UI/UX 개편안 v3.

## 근거와 분석 범위

브라우저에서 영문 자동 생성 자막 전체를 추출해 검토했다. 10:07(자막 위치·안전영역), 18:54(전사 선택·강조), 25:12(편집기·타임라인·구도)의 화면도 표본 확인했다. 전체 영상을 연속 시청하거나 OpusClip 유료 계정 안에서 직접 기능을 시험한 결과는 아니다.

영상은 당시 제품의 설명·시연 근거다. 현재 플랜별 제공 조건, 생성 품질·처리 속도, 내부 모델·큐·DB·코드 구조의 증거로 사용하지 않는다. 공개 화면에서 보이는 작업 흐름을 호루박 코드와 비교하며 경쟁사의 코드·브랜드·미디어 자산은 가져오지 않는다.

## Council 판정

### Selected Panel
design triad · full 모드 · Rams(디자인, 도메인 가중치1.5), Torvalds(구현1.0), Watts(사용 흐름1.0).
재진술 관문 후 독립 분석→익명 교차 검토→실명 최종 입장의 3라운드. 제2라운드는 Member A/B/C로 익명화했다.

### Chairman
비토론 의장: 루트 조정자, OpenAI 호스트 상속 모델. 사용 가능한 독립 외부 제공자 호출 없이 같은 제공자 안에서 수행했다. 의장은 세 멤버의 토론에 참여하지 않고 판정을 종합했다. 서로 다른 회사의 모델 합의로 해석하지 않는다.

### Acceptable Compromises
이번 범위는 후보 탐색/일괄 보관, 네 비율/일반 가이드, redo/도움말에 제한한다. 자동 분석·새 타임라인·브랜드 일괄 적용·생성·게시를 동시에 구현하지 않는다. 샘플 후보3개로 대량 탐색의 실제 효용을 확정할 수 없다.

### Kill Criteria
If 이번 검수 종료(2026-11-06 기준 작업)까지 화면비와 JSON 목표가 다르거나1280px 핵심 조작이 가로로 이탈하면, invalidated → 해당 화면비 변경을 완료 범위에서 제외하고9:16 기본값으로 복구한다.
If 같은 후보 재보관이 기존 클립을 덮거나 중복을 만들면, invalidated → 일괄 보관을 제외하고 단일 채택을 유지한다.
If undo/redo가 다른 클립을 바꾸거나 입력창의 텍스트 undo를 가로채면, invalidated → 전역 편집 단축키를 제외하고 버튼 복구부터 수정한다.

### Concrete Next Step
세 기능의 파일 소유권·공통 데이터·완료 기준을 담은 구현 계약서를 작성한다. 해당 계약을 기준으로 구현과 검수를 진행한다.

### Unresolved Questions
실제 후보가 수십 개일 때 탐색 시간과 채택률, 플랫폼별 정확한 안전 여백, 다중 길이 프로필의 평가 기준은 미확정이다. 실제 서버 기능은 기존 담당/API 책임과 맞춰야 한다.

### Key Agreements
데스크톱 전용·기존 데이터 보존. 이미 채택한 후보는 중복 생성하지 않는다. 필터 변경 시 숨은 선택을 남기지 않는다. 안전영역은 일반 가이드다. JSON은 계속 rendered:false다. 연결되지 않은 AI 기능을 가짜 성공으로 채우지 않는다.

### Key Disagreements / Minority Report
Torvalds는 redo 단독 구현을 우선하는 입장을 유지했다. Rams·Watts도 단일 클립 데모에서는 기능 묶음이 과할 수 있다는 반례를 인정했다. 현재는 반복 제작까지 확장하라는 사용자 요청에 따라 제한된 세 기능을 독립 검증하는 조건으로 채택했다. 합의를 이유로 이 유보를 삭제하지 않는다.

### Decision Options
1. redo만 제공: 가장 작고 검증이 간단하나 반복 후보 채택과 화면비 제약은 유지.
2. 제한된 세 기능 제공(채택): 반복 제작 흐름을 보완하되 비율·저장·키보드 결합 검증 부담을 수용.
3. 브랜드·텍스트 컷·자동 게시까지 일괄 확장: 기능 폭은 넓지만 현재 데이터/서버 경계를 넘어 이번 범위에서 제외.

### Recommended Next Steps
계약에 따라 세 기능을 구현하고, 데이터 이전·일괄 채택·비율/JSON·redo·키보드·데스크톱을 검증한다. 이후 전사/cue/segment 계약, 실제 입력·인증·분석·렌더, 브랜드 재사용, 배포 순으로 연결한다. 기존 EXT-004/005/006/008/012/019와 추적성을 유지한다.

### Confidence
medium. 현재 코드와 영상 근거를 연결한 구현 판단에는 근거가 있으나 실제 대량 사용자 시험·AI 성능 평가·경쟁사 내부 API 검증을 수행하지 않았다.
