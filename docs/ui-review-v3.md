# 호루박 UI/UX v3 검수 기록

검수일: 2026-11-06 (사용자 시간대 기준). 대상: `ui-design-spec-v3.md`의 데스크톱 프론트엔드 구현.

## 결과

단위 테스트 **38/38**, TypeScript 및 Vite 프로덕션 빌드 통과. 데스크톱 화면 조합 **96/96**, 실제 브라우저 기능 시나리오 **14/14** 통과. 검사 범위에서 브라우저 실행 오류는 없었다. 이는 프론트엔드 데모 검증이며 제품 전체의 서버 기능 완료 판정이 아니다.

## 화면 검수

1280×800·1440×900·1920×1080, 라이트·다크 각각에서 16개 경로를 검사했다. 요청한 테마와 실제 적용 테마의 일치, 가로 넘침, 화면 안에 보이는 필수 조작의 가로 이탈, 페이지별 h1과 브라우저 실행 오류를 확인했다. 긴 화면은 세로 스크롤을 사용한다. 일러스트의 의도된 내부 크롭은 앱 조작 이탈과 구분했다.

대상은 프로젝트 목록·새 영상·프로젝트 허브의 후보/클립/원본/작업 탭·편집·결과·라이브러리·작업센터·게시·팀·성과·설정·로그인·회원가입이다. 로그인·가입은 별도 비로그인 화면 상태도 확인했다.

실행 데이터: [화면 검수 행렬](ui-v3-layout-matrix.json). 대표 화면은 [프로젝트](screenshots/v3/layout-projects-dark-1440.png), [새 영상](screenshots/v3/layout-new-dark-1440.png), [편집](screenshots/v3/layout-editor-light-1440.png).

## 시각 검토와 수정

Stageshow 정적 예시를 원본 구도와 비교하고 별도 에이전트가 새 시각으로 검토했다. 선택 후보와 앞쪽 클립의 제목을 일치시키고, 목록 간격·다크 포인트 대비를 보완했다. 최종 라이트1440·라이트1280·다크1440·모션 줄이기1440의 **4개 정적 촬영은 --still --gate 통과**다. 애니메이션 검수 결과는 아니다. 자세한 기록은 [REHEARSAL.md](../frontend/src/components/stageshow/REHEARSAL.md)를 따른다.

독립 검수자가 실제 영상 화면에서 `52.208333초`처럼 긴 표시를 발견했다. 편집·클립 목록·맥락 비교의 초 단위 요약을 최대 소수 한 자리로 수정했다. 원본 시간·편집 값·JSON의 정밀도는 변경하지 않았다. 수정 후 브라우저 기능과 프로덕션 빌드를 재실행했다.

## 검수 범위와 남은 작업

- **모바일 화면은 구현·검수 대상에서 제외**했다. 데스크톱 1280px 이상이 지원 범위다.
- 실제 인증·서버 권한·사용자 간 격리·AI 분석 품질·처리 성능·업로드·MP4 합성·게시·협업·과금은 미연결이다. 이번 결과로 해당 기능의 완료나 보안을 보증하지 않는다.
- 스크린 리더·실제 OS 모션 줄이기·새 사용자의 사용성·다른 브라우저 엔진은 별도 검수가 필요하다.
- 화면 행렬은 기본 상태를 대상으로 한다. 모든 대화상자·최악 데이터·오류 조합의 전수 검사가 아니다.
- 기존 30~60초 편집 규칙을 유지한다. 출력 길이 프로필 확장, 시간별 자막 편집·자동 크롭·실제 파형/드래그 트림은 후속 구현이다.
- 기능 시험의 저장은 테스트 브라우저 localStorage다. 브랜드는 프리셋 저장·미리보기까지만 제공하며 최종 영상 적용과 구분한다.

기존 v2 기록과 작업 중인 변경은 보존했다. 이번 작업에서 Git 커밋·푸시는 수행하지 않았다.
