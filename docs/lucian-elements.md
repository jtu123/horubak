# Lucian UX/UI 사용 내역

## 현재 화면: 214번 복원·로그인 중앙 정렬 (2026-10-23)

최신 요청에 따라 214번 원본을 CLI에서 다시 받아 메인을 `a a b / c d b / e e e` 5칸으로 복원했습니다. A 새 하이라이트, B 최근 작업·검색, C 프로젝트 현황, D 내 공간, E 프로젝트 목록입니다. 아바타 모이기·45ms 타이핑·막대 성장·방패 파동·아이콘 흐름과 원본 모션 곡선을 유지합니다. 기존의 긴 소개와 영문 소제목은 복원하지 않고 짧은 기능 이름을 사용합니다. 고정 340×340 외곽은 기존 전체 페이지 적용에 맞춰 확장하고 375px에서는 두 열/전체 폭을 섞어 재배치합니다.

브라우저 댓글 1의 로그인 소개 영역은 DOM에서 제거했습니다. 댓글 2의 로그인 폼은 가로 중앙으로 옮겼고 회원가입에도 같은 배치를 적용했습니다. 902px·375px에서 실제 폼 중앙과 문서 콘텐츠 중앙이 일치하는지 확인했습니다. 아래의 단일 목록 간소화 항목은 변경 전 이력입니다.

## 이전 화면: 간소화 (2026-10-23)

사용자의 최신 요청에 따라 메인의 소개 문구·영문 소제목·자동 타이핑·통계·중복 최근 목록·바로가기 카드를 제거했습니다. 214번에서 가져온 둥근 카드 표면을 단일 프로젝트 목록으로 재구성하고, 제목·검색·장르·정렬·새 영상 등록을 중심으로 배치했습니다. 이전 5칸 구성은 아래에 이력으로 남깁니다.

프로젝트 카드의 영문 샘플 배지·원본 파일명·중복 메타데이터도 줄였습니다. 038번 메뉴·046번 빠른 실행·092번 필터 복구는 그대로 작동하며, 로그인·회원가입·등록·처리·편집·결과 화면의 긴 안내도 짧게 바꿨습니다. 042번 단계 표시와 사이드 레일의 소개 카드는 현재 화면에서 제거했습니다. 데모·브라우저 저장·미연결 기능 안내, 추천 이유·전사·맥락 근거는 유지합니다.

현재 검수와 화면은 [UI 검수 기록](ui-review.md)의 간소화 항목을 참고하세요.

최신 검수 상태(2026-10-23): 사용자의 브라우저 허용 설정이 반영되어 메인 화면의 실제 브라우저 검수를 진행했습니다. 아래의 보안 제한·미완료 표기는 최초 구현 시점의 기록입니다. 현재 확인한 범위와 수정 사항은 [UI 검수 기록](ui-review.md)을 참고하세요.

## 호루박 테마 변경 (2026-10-23)

사용자 요청에 따라 Lucian 요소의 상호작용은 유지하고 외형을 조정했습니다. 공통 시각 스타일은 `frontend/src/styles/theme.css`에 있습니다. 토스 공식 TDS의 [blue500 색상](https://tossmini-docs.toss.im/tds-mobile/foundation/colors/) `#3182F6`를 주요 버튼에 적용했습니다. 밝은 중립색 바탕, 둥근 모서리, 은은한 그림자로 화면을 통일하고, 사이드 레일은 밝은 카드로 변경했습니다. 가입 폼 244번은 입력 가독성에 맞춰 340×510 크기로 확장했습니다. 480px 이하 프로젝트 목록은 한 열로 표시합니다. 소개 영역은 직접 작성한 SVG 입체 그래픽을 사용합니다. 오류의 빨강과 완료의 초록은 상태 전달을 위해 유지합니다.

적용 범위: 032 업로드, 039 탭, 040 사이드 레일, 042 단계 표시, 062 로그인, 070 알림, 244 회원가입. 다크 테마·375px·포커스·reduced motion 스타일을 포함했습니다. 실제 브라우저 시각/키보드 검수는 보안 정책으로 미완료입니다.

## 214번 메인 기능 소개 (2026-10-23)

[#214 칸마다 살아나는 벤토 기능 소개](https://lucianlabs.dev/uxui-prompt/#214)를 메인 화면 상단에 적용했습니다. 원본 340×340 외곽과 비대칭 5칸 그리드, 45ms 타이핑, 호버·막대·방패·아이콘 모션을 React로 옮겼습니다. 타이머와 matchMedia 리스너는 정리하며, 모션 줄이기 변경도 반영합니다. 칸을 버튼/링크로 만들어 샘플 편집, 실제 검색창 포커스, 브라우저 저장 안내, 영상 등록에 연결했습니다. 데모에서 제공하지 않는 동시 편집·종단 암호화·40개 외부 연동 문구는 제거했습니다. 파란 테마를 사용하고 모바일은 세로 배치 및 max-width:100%로 제한했습니다. 기존 동작 카드와 목록 영역은 계속 사용할 수 있습니다. 브라우저 시각·키보드 실검수는 도구 보안 제한으로 미완료입니다.

## 214번 전체 메인 화면 확장 (2026-10-23)

사용자의 전체 화면 적용 요청에 따라 340×340 소개 요소를 메인 페이지 전체로 확장했습니다. 원본을 그대로 확대하는 대신, 동일한 `a a b / c d b / e e e`의 다섯 칸 배치에 실제 작업 기능을 담았습니다. 외곽 크기·내부 간격·글자 크기·칸 높이는 페이지 내용에 맞게 조정했습니다. 원본 라이선스와 호버의 350ms 곡선, 45ms 타이핑, 아바타 모이기, 막대 성장, 방패 파동, 아이콘 흐름은 유지합니다. 최근 목록은 장식용 검색 막대를 실제 프로젝트 행으로 바꾸고 해당 호버 곡선을 적용했습니다.

- A: 작업 시작·새 영상 등록·샘플 편집·타이핑 안내.
- B: 실제 프로젝트 검색·최근 작업 3개·검색 초기화. Ctrl/Cmd+K로 검색창에 접근.
- C: 현재 사용자의 전체 프로젝트·처리/편집/결과 수 표시. 막대는 장르별 개수를 바탕으로 한 장식이며 추가 분석을 실행하지 않음.
- D: 즐겨찾기·결과 보관함·브라우저 저장 안내.
- E: 전체 프로젝트 목록·장르 필터·정렬·카드/목록 보기·이름 변경·즐겨찾기·삭제·빈 상태.

메인과 즐겨찾기/결과 보관함은 상단 내비게이션을 사용하는 넓은 캔버스로 변경했습니다. 900px 이하에서는 두 열로 재배치하고 600px 이하에서는 한 열로 표시합니다. 모바일 목록 보기의 관리 버튼은 세로로 배치합니다. 모든 인터랙티브 항목에 키보드 포커스를 제공하며 타일은 focus-within에도 반응합니다. 입력 중 focus가 같은 타일 안에서 이동할 때 애니메이션을 재시작하지 않습니다. 타이핑 타이머와 미디어쿼리 이벤트를 정리하고 모션 줄이기 환경에서는 자동 움직임을 멈춥니다.

타입 검사, 기존 단위 테스트 8개 및 소스 렌더링 10개 사례(전체/즐겨찾기/결과, 라이트/다크·모션 줄이기, 빈 목록, 제목의 HTML 이스케이프)를 확인했습니다. 프로덕션 빌드를 확인했습니다. 실제 브라우저의 시각·375px·키보드 동작 검수는 도구 보안 제한으로 미완료입니다.

## 인터페이스 요소 추가 (2026-10-23)

라이브러리에서 검색·메뉴·빈 상태를 찾아 046·038·092 세 요소의 원본을 내려받았습니다. 원본 CSS와 MIT 주석은 `frontend/src/components/lucian/interface-*.css`에 유지하고, React 컴포넌트의 데이터·이벤트를 실제 브라우저 프로젝트에 연결했습니다. 통합 스타일은 `frontend/src/styles/interface-additions.css`에 분리했습니다.

- **046:** 원본 360×460 팔레트, 56px 검색칸, 46px 선택 행, 600ms 펼침·500ms 닫힘·650ms 실행 피드백을 유지합니다. 모바일은 화면 폭·높이 안으로 제한합니다. 기존 Ctrl/Cmd+K 프로젝트 검색과 충돌하지 않도록 단축키를 Ctrl/Cmd+Shift+K로 바꿨습니다. 방향키 순환, Enter 실행, Escape 닫기·포커스 복원, IME 입력 보호와 타이머 정리를 제공합니다. 실제 프로젝트 목록·새 영상 등록·즐겨찾기·결과·테마 명령을 사용합니다.
- **038:** 원본 200px 메뉴·모서리·그림자·스프링 곡선을 유지합니다. 카드 내부의 잘림을 피하려고 document.body 포털로 배치하고 화면 가장자리에서 위치를 보정합니다. 하위 메뉴는 같은 스프링 곡선의 패널 전환으로 옮겼습니다. 방향키·Home/End·좌우 하위 메뉴·Escape·바깥 클릭을 지원합니다. 삭제는 기존 확인창을 거칩니다. 모바일 더 보기 버튼과 길게 누르기 처리를 포함합니다.
- **092:** 원본 340×480 외곽·돋보기 모션·조건 칩의 330ms 사라짐을 유지하고 모바일 폭을 제한합니다. 기존 검색창과 중복되지 않게 내부 검색칸은 현재 조건 요약으로 바꿨습니다. 표시하는 복구 개수는 현재 사용자의 프로젝트와 남겨 둘 필터로 계산합니다. 필터를 해제한 뒤 기존 검색창으로 포커스를 복원합니다.

명시적 라이트·다크 테마에서 원본의 보라색 토큰이 우선하던 문제를 수정해 세 요소도 호루박의 파란색을 사용합니다. 타입 검사·단위 테스트 12개·프로덕션 빌드를 통과했습니다. 실제 브라우저 검증 범위와 캡처는 [UI 검수 기록](ui-review.md)에 있습니다. 운영체제의 모션 줄이기 설정과 실제 터치 기기의 길게 누르기는 실기기 검증을 수행하지 않았습니다.
