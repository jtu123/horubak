## 재배포 직전 버전으로 복구

[rollback-latest-demo.ps1](../../scripts/deployment/rollback-latest-demo.ps1)은 Pages `6d3fb91c-72cf-4d3d-90f7-69f914ab7c11`를 복구 목표로 고정한다. Worker 목표는 현재와 같아 변경을 건너뛴다. 기본 실행은 계획만 출력하며 네트워크나 운영 상태를 바꾸지 않는다.

```powershell
pwsh -File ./scripts/deployment/rollback-latest-demo.ps1
```

실제 복구에는 `-Apply`와 대상 계정의 Pages Write 권한을 가진 `CLOUDFLARE_API_TOKEN`이 필요하다. 기존 Wrangler 인증으로 Worker 상태를 조회한다. 키 값은 채팅·Git·문서에 넣지 않는다. API 토큰이 없으면 [Cloudflare 배포 목록](https://dash.cloudflare.com/2eb0b2e89370b1d4f23f4f98fbee4ce6/pages/view/horubak)에서 위 직전 Pages의 운영 롤백을 실행하고 실제 운영 ID를 확인한다.
